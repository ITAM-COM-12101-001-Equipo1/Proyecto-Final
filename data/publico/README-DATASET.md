# Remuneraciones de Servidores Públicos - CDMX

## Description

Remuneraciones de 246,821 servidores públicos del Gobierno de la Ciudad de México. Incluye puesto, sector, tipo de contratación, antigüedad, género, edad, sueldo bruto y neto.
